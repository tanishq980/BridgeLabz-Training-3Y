# DOM Assignment 7 Solutions

Contains separate JavaScript files q1.js through q9.js, following the supplied PDF.
Each file expects the HTML elements/IDs named in the JavaScript selectors.

Include the relevant script in the HTML page using:
<script src="q1.js" defer></script>

Required main element IDs:
Q1: productInput, addButton, productList
Q2: messageBox, characterCounter, resetButton
Q3: .form-step, nextButton, backButton, summary (each step has an input with name=name/email/password)
Q4: buttons with data-theme-choice="light", "dark", or "blue"
Q5: gallery, imageModal, modalImage, modalContent
Q6: searchInput, studentTable, noResultsMessage
Q7: trackingBox, coordinateDisplay
Q8: customDropdown, dropdownToggle, dropdownOptions
Q9: detailsForm, name, email, password, nameError, emailError, passwordError, successMessage

Use HTML/CSS for the visual elements; the assignment allows only core JavaScript (ES6+), HTML, and CSS.
